Getting Started

1. Create a GitHub Repository

  1. Go to github.com/new
  2. Name it something like logik-blueprints
  3. Choose Public or Private
  4. Click Create Repository
  5. Copy the repository name

2. Create a GitHub Personal Access Token (PAT)

  1. Go to github.com/settings/tokens
  2. Click Generate new token → Generate new token (classic)
  3. Name it: Logik Blueprint Admin
  4. Expiration: 90 days or never
  5. Select scope: repo (full control of repositories)
  6. Click Generate token
  7. ⚠️ Copy the token immediately (you won't see it again!)

3. Get Your Logik Admin API Key

  1. Log in to your Logik instance as an admin
  2. Go to Admin Settings → API Keys
  3. Create a new API key named Admin Masterlord
  4. Make sure it has permissions for Blueprints, Rules, and Scripts
  5. Copy the API key

4. Enter Your Credentials

  1. Logik Admin API Key: Paste your API key from step 3
  2. GitHub Personal Access Token: Paste your PAT from step 2
  3. GitHub Username: Your GitHub username (not organization)
  4. Repository Name: The repository name from step 1
  5. Click Save Settings

Logik Admin API Profiles

Create profiles for different Logik environments. Each profile stores an environment identifier (e.g., miratech-prod, miratech-sandbox02) and its corresponding Admin API Key. The extension will auto-detect which profile to use based on your current Logik instance URL. Get API Keys from: Admin → Utilities → Admin API Keys
